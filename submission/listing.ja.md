# プラグイン掲載情報 — 日本語

## 名前

Token Efficient

## カテゴリ

生産性 / Productivity

## 短い説明

品質を落とさず、不要なコンテキストを減らします。

## 詳細説明

Token Efficientは、ChatGPTとCodexが、対象を絞ったコンテキスト、ファイル読み込み、検索、ツール出力、簡潔な回答でタスクを完了できるようにします。利用者の意図、安全規則、権限、必要な検証は常に優先されます。明示的に発動するスキルで、外部サーバーや認証は必要ありません。
