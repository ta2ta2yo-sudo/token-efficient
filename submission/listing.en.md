# Plugin listing — English

## Name

Token Efficient

## Category

Productivity

## Short description

Use less context without sacrificing quality.

## Long description

Token Efficient helps ChatGPT and Codex complete work with focused context, targeted file reads, bounded searches, compact tool output, and concise responses. It remains subordinate to user intent, safety rules, permissions, and required verification. The skill is explicitly invoked, uses no external server, and requires no authentication.
