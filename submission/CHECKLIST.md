# Public submission checklist

This repository prepares the technical package and public materials. The account owner must complete identity, attestation, review submission, and post-approval publication in the OpenAI Platform.

- [x] Skills-only plugin; no MCP server, app, external account, or authentication
- [x] `.codex-plugin/plugin.json`
- [x] Final skill bundle under `skills/token-efficient/`
- [x] Public logo source and upload-ready PNG assets
- [x] English and Japanese listing copy
- [x] Three starter prompts
- [x] Five positive and three negative test cases
- [x] Public website, support, privacy, and terms URLs
- [ ] OpenAI developer or business identity verified by the account owner
- [ ] Apps Management write permission confirmed by the account owner
- [ ] Policy attestations completed by the account owner
- [ ] Package submitted for OpenAI review
- [ ] Approved plugin published to the Universal Plugins Directory

Submission guide: https://developers.openai.com/plugins/deploy/submission
