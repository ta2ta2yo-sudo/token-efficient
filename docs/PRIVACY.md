# Privacy Policy / プライバシーポリシー

Last updated: August 18, 2026

## English

Token Efficient is a skills-only plugin made of instructions for ChatGPT and Codex. It does not operate an external server, require an account, use authentication, set cookies, or independently collect, store, sell, or transmit personal data.

The plugin may guide the host product to work with information and tools that the user has already provided or authorized. Processing performed by ChatGPT, Codex, or a user-selected tool is governed by that product's terms, privacy policy, permissions, and the user's instructions. Token Efficient does not add a separate data destination.

Do not provide secrets or private data unless they are necessary for the task and appropriate for the host product and selected tools.

Questions or privacy concerns can be filed through [GitHub Issues](https://github.com/ta2ta2yo-sudo/token-efficient/issues).

## 日本語

Token Efficientは、ChatGPTとCodex向けの指示だけで構成されるskills-onlyプラグインです。外部サーバーの運用、アカウント登録、認証、Cookieの設定を行わず、個人データを独自に収集・保存・販売・送信しません。

このプラグインは、利用者がすでに提供または許可した情報やツールをホスト製品が扱う際の進め方を案内する場合があります。ChatGPT、Codex、または利用者が選択したツールによる処理には、それぞれの規約、プライバシーポリシー、権限、利用者の指示が適用されます。Token Efficientが別のデータ送信先を追加することはありません。

秘密情報や個人情報は、タスクに必要であり、ホスト製品と選択したツールで扱うことが適切な場合に限って提供してください。

質問やプライバシー上の懸念は[GitHub Issues](https://github.com/ta2ta2yo-sudo/token-efficient/issues)で受け付けます。
