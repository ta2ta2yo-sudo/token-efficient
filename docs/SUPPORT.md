# Support / サポート

## English

- Read the installation and usage guidance in the [README](../README.md).
- Search existing [issues](https://github.com/ta2ta2yo-sudo/token-efficient/issues) before opening a new one.
- Report suspected security vulnerabilities privately through [GitHub Security Advisories](https://github.com/ta2ta2yo-sudo/token-efficient/security/advisories/new), not in a public issue.

Please include the host product (ChatGPT or Codex), invocation method, expected behavior, observed behavior, and a minimal non-secret example.

## 日本語

- インストール方法と使い方は[README](../README.md)を確認してください。
- 新規報告の前に既存の[Issues](https://github.com/ta2ta2yo-sudo/token-efficient/issues)を検索してください。
- セキュリティ上の問題は公開Issueではなく、[GitHub Security Advisories](https://github.com/ta2ta2yo-sudo/token-efficient/security/advisories/new)から非公開で報告してください。

報告には、利用製品（ChatGPTまたはCodex）、発動方法、期待した動作、実際の動作、秘密を含まない最小の例を記載してください。
